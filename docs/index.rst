How to Get Help From Big Fish Games
===================================

If you need help with a Big Fish Games account, game, purchase, billing issue, Game Club membership, or technical problem, there are several ways to find assistance. Big Fish Games provides an official Help Center with troubleshooting guides, frequently asked questions, and a customer-support request system.

The Help Center is the best place to start because many common problems already have step-by-step solutions. If you cannot find an answer, you can submit a request to Big Fish Games Customer Support.


Start With the Big Fish Games Help Center
-----------------------------------------

The easiest way to get help is to visit the official Big Fish Games Help Center.

The Help Center contains support information for several categories, including:

* Account and sign-in problems.
* Billing and purchasing questions.
* Technical problems.
* Big Fish Game Club.
* Mobile games.
* Game installation and downloading.
* Game Manager problems.
* Gameplay questions.
* Refund and reimbursement information.

Before submitting a support request, search the Help Center for your specific problem. You may find an existing article that explains how to fix the issue without contacting Customer Support.

For example, you can search for:

* ``Forgot password``
* ``Game will not start``
* ``Game crashes``
* ``Game will not install``
* ``Missing purchased game``
* ``Billing problem``
* ``Game Club question``
* ``Login problem``

Big Fish Games regularly updates its Help Center, so using the current official support website is preferable to relying on old contact information from third-party websites.


How to Submit a Support Request
-------------------------------

If you cannot solve your problem using the Help Center, you can contact Big Fish Games Customer Support by submitting a support request.

The general process is:

#. Open the official Big Fish Games Help Center.
#. Search for your problem.
#. Read the relevant support articles.
#. Select ``Submit a request`` if you still need assistance.
#. Choose the appropriate support category.
#. Enter the requested contact information.
#. Describe your problem in detail.
#. Provide relevant account, game, order, or device information.
#. Attach screenshots or other useful files when necessary.
#. Review the information you entered.
#. Submit your request.

Big Fish Games says that after you submit the form, you should receive an automated email confirming that the company received your question. A Customer Support response will then be sent to the email address you provided.

Keep the confirmation email until your issue has been resolved. It can be useful if you need to provide additional information or follow up on the same support case.


What Information Should You Provide?
------------------------------------

Providing detailed information can make it easier for Customer Support to understand your problem.

The information you should provide depends on the type of issue.

For most requests, useful information may include:

* Your Big Fish Games account email address.
* The name of the game involved.
* A description of the problem.
* Error messages or error codes.
* Your device information.
* Your operating system.
* Steps you have already taken to troubleshoot the problem.
* Relevant order numbers.
* Screenshots of the problem.
* Diagnostic information when requested.

Try to explain exactly what happens instead of using a short statement such as ``My game does not work``.

For example::

   The game opens normally, but it closes after the loading
   screen. I restarted my computer and reinstalled the game,
   but the problem continues.

This gives the support team a clearer description of the issue and the steps you have already attempted.


Getting Help With Account Problems
----------------------------------

If you cannot sign in to your Big Fish Games account, start by checking the Account and Sign-in Help section.

Common account problems include:

* Forgotten passwords.
* Login errors.
* Problems receiving password-reset emails.
* Difficulty recovering previously purchased games.
* Problems accessing an older account.

If you forgot your password, use the password-reset option provided by Big Fish Games.

If you do not receive the reset email, check your Spam or Junk folder. Make sure you are checking the email address associated with your Big Fish Games account.

If you still cannot access your account, submit a support request. Explain the problem and provide the email address associated with the account when appropriate.

Do not send your password to Customer Support.


Getting Help With Technical Problems
------------------------------------

Big Fish Games provides technical support for problems involving games, downloads, installation, and the Big Fish Games application.

Common technical problems include:

* A game will not start.
* A game crashes.
* A game freezes.
* A game will not install.
* A download fails.
* A game displays an error message.
* A game shows a blank screen.
* The Big Fish Games application displays an error.

Before contacting Customer Support, check the technical troubleshooting articles in the Help Center.

For example, Big Fish Games provides troubleshooting information for PC game launch problems. Depending on the game and system, suggested solutions can include checking compatibility settings, security software, and other system configurations.

When submitting a technical support request, include:

* Game title.
* Operating system.
* Error message or error code.
* Description of the problem.
* Steps that cause the problem.
* Troubleshooting steps you have already tried.
* Diagnostic information if requested.

For PC and Mac issues, Customer Support may request a Dr. Felix Diagnostics Report. If the support team requests this report, follow the instructions provided in the relevant Help Center article.


Getting Help With Purchases and Billing
---------------------------------------

You can also contact Big Fish Games if you have questions about purchases, billing, payments, refunds, or missing games.

For a purchase-related problem, provide the relevant order number whenever possible.

Useful information can include:

* Order number.
* Date of purchase.
* Name of the game.
* Description of the billing issue.
* Billing address.
* Email addresses that may have been used for the purchase.

Big Fish Games advises customers not to provide a complete payment-card number.

If payment-card information is required for identification, follow the instructions provided by the official support team. Big Fish Games indicates that the first four and last four digits may be useful for certain billing questions.

Never send your account password.


Getting Help With Game Club
---------------------------

If you are a Big Fish Game Club member, you can use the Help Center to find information about membership, purchases, billing, and other Game Club questions.

You may need assistance if:

* You have a question about your membership.
* You want to understand a Game Club charge.
* You have a billing problem.
* You have questions about a Game Club purchase.
* You cannot access a game associated with your account.
* You need information about cancellation.

When contacting Customer Support, describe the exact Game Club issue and include relevant order or account information when available.


Getting Help With Mobile Games
------------------------------

Big Fish Games also provides support for mobile and free-to-play games.

If you need help with a mobile game, provide as much information about your game profile as possible.

Some free-to-play games use a unique in-game ID to identify your player profile. Big Fish Games explains that this ID can help its support team locate your profile more quickly.

Depending on the game, the identifier may be called:

* User ID.
* AccountID.
* Friend Code.
* In-game ID.

If you cannot locate your in-game ID, provide your email address and other useful information, such as your profile name, level reached, and amount of in-game currency.

The exact location of an in-game ID can differ between games, so check the Help Center for instructions for your particular title.


Getting Help With Refunds
-------------------------

If you are looking for help with a refund, review the current Big Fish Games refund and reimbursement policy before submitting a request.

Big Fish Games currently states that purchases made within 48 hours may be eligible for a full refund to the original payment method or Big Fish Points, subject to the applicable policy.

For purchases between 48 hours and 90 days old, the company states that technical support assistance is available and that reimbursement with Big Fish Points may be possible when a verified technical problem cannot be resolved.

Purchases more than 90 days old are generally not eligible for refunds or points under the current policy, although continued technical support may still be available.

Policies can change, so check the current official refund policy before relying on a particular eligibility period.


How Long Does Big Fish Games Take to Respond?
---------------------------------------------

Big Fish Games states that its average Customer Support response time is typically around ``24-72 hours``.

The current Help Center also states that the first response for support tickets is roughly ``2-3 business days``.

Response times can vary depending on the number of requests Customer Support is handling.

After submitting a request, allow sufficient time for the support team to respond before submitting another request.


What to Do While Waiting for Support
------------------------------------

After submitting a request, check your email regularly.

Look in the following folders if you do not see a response:

* Inbox.
* Spam.
* Junk.
* Promotions.
* Other filtered folders.

Big Fish Games recommends adding ``support@bfgentertainment.zendesk.com`` to your safe-senders list or address book to help prevent support emails from being filtered.

If you already submitted a support request, do not send multiple new requests about the same issue.

If you need to provide additional information, reply to the confirmation email you received. This keeps the additional information associated with your existing support case.


How to Make Your Support Request Better
---------------------------------------

A well-written support request can help Customer Support understand your problem more quickly.

Use a descriptive subject when the form provides a subject field.

For example::

   Game crashes when opening

is better than::

   Help

In the message, explain:

#. What happened.
#. When the problem started.
#. Which game is affected.
#. What device you are using.
#. Which operating system you are using.
#. What you have already tried.
#. Whether the problem happens every time.
#. Any error messages that appear.

If the problem is visual, consider attaching a screenshot.

For technical issues, provide diagnostic information if the Help Center or Customer Support requests it.


Protect Your Personal Information
---------------------------------

When getting help from Big Fish Games, protect your account and payment information.

Never provide your password to anyone claiming to be a Big Fish Games support representative.

Do not send your complete credit-card number.

Avoid sharing unnecessary personal information in your support request.

Use the official Big Fish Games Help Center when looking for support. Be cautious with websites or individuals that claim to offer Big Fish Games customer service but are not part of the official support system.


Phone Support and Other Contact Options

Frequently Asked Questions
---------------------------

How can I get help from Big Fish Games?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Visit the official Big Fish Games Help Center. Search for your issue first, and if you cannot find a solution, use the ``Submit a request`` option to contact Customer Support.

How long does Big Fish Games Support take?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Big Fish Games states that its average response time is approximately ``24-72 hours``. The current Help Center also describes the first-response time as roughly ``2-3 business days``.

What information should I include in a support request?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Include the game title, description of the problem, error messages, troubleshooting steps, device and operating-system information, and relevant order or account information.

Can I send my credit-card number to support?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

No. Do not send your complete credit-card number. Follow the official instructions if Customer Support requires limited payment information for a billing investigation.

What if I do not receive a response?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Check your Spam and Junk folders. Make sure your email address is correct and add the official support email address to your safe-senders list if necessary.

Should I submit another ticket?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

If you already submitted a request, do not create another request for the same problem. Reply to the confirmation email if you need to provide additional information.

Can Big Fish Games help with mobile games?
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Yes. For supported mobile and free-to-play games, provide the game name and relevant player information. If available, include your in-game ID, User ID, AccountID, or Friend Code.


Conclusion
----------

Getting help from Big Fish Games is usually straightforward when you begin with the official Help Center. The Help Center provides troubleshooting articles for account, technical, billing, Game Club, mobile, and gameplay issues.

If an existing article does not solve your problem, submit a support request with detailed and accurate information. Include the game name, description of the problem, error messages, troubleshooting steps, and relevant account or order information.

For mobile games, include your in-game identification information when available. For billing issues, provide the requested order information but never send your password or complete payment-card number.

After submitting a request, save the confirmation email and check your Inbox, Spam, and Junk folders. Big Fish Games currently reports an average response time of approximately 24-72 hours, while its Help Center indicates that first responses are currently taking roughly 2-3 business days.

Using the official Help Center, providing complete information, and keeping all follow-up messages within the original support request are the best ways to get assistance from Big Fish Games.
